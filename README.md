# tabereru-site

iOS アプリ「たべれる」のプライバシーポリシーとサポートページ。

**このリポジトリは公開ページを置くためだけのもの。** アプリ本体のソースは別リポジトリ（private）にある。

## なぜ別リポジトリなのか

App Store Connect はプライバシーポリシーURLとサポートURLの入力を必須にしており、
「データを収集しない」アプリでも URL 欄は省略できない。
アプリ本体のリポジトリは private で、Free プランでは private リポジトリから
GitHub Pages を公開できないため、公開ページだけをここに分けている。

**アプリはこのページに一切依存しない。** ページが落ちてもアプリの動作は変わらない
（アプリ本体はサーバーを持たない方針で、外部通信はレシピ検索リンクを開く用途のみ）。

## 構成

| ファイル | 用途 |
|---|---|
| `index.html` | トップ。アプリの概要 |
| `privacy.html` | プライバシーポリシー（App Store Connect に登録するURL） |
| `support.html` | サポート・よくある質問（同上） |
| `style.css` | 3ページ共通。ダークモード対応 |

依存ライブラリなし。ビルド不要。素の HTML と CSS のみ。

## 公開設定

GitHub Pages を `main` ブランチのルートから公開する。

内容を変更したら、アプリ側の実装と食い違っていないかを確認すること。
特にプライバシーポリシーの「ネットワーク通信」の節は、
アプリが実際に通信する箇所（レシピ検索リンクのみ）と一致している必要がある。
