子供の「食べられた」を記録して、今夜作るものを決める

子供の好き嫌いは覚えていられるようで、覚えていられません。園の給食では食べたのに家では食べない。あれは大丈夫であれはだめ。そうして毎日「今夜何を作るか」で手が止まります。

このアプリは、食べられたものと苦手なものを記録しておいて、苦手な食材が入っていない料理を候補として出します。園の給食で出て、実際に食べられた料理を優先して出すので、家庭のレパートリーがそのぶん増えていきます。

できること

  • 台帳 — 料理を「食べた / だめだった / 未挑戦」で記録する。1タップで切り替わります
  • 提案 — 苦手な食材を含む料理を外した候補を出す。費用感でも絞れます
  • 新しい食材 — まだ食べていない食材が1つだけ入った料理に絞れます。だめだったときに原因を1つに絞れる形にしてあります
  • 献立の入力 — 園の献立表を月ごとに入力する。写真からの読み取りにも対応しています（読み取りのみ買い切り）
  • シールで記録 — 子供自身が「たべた」「のこした」を貼って記録できます
  • ふりかえり — 食べられた食材と、園から輸入できた料理が増えていく様子を見られます
  • 書き出し — 記録はいつでもテキストまたは JSON で持ち出せます

作りかたの方針

  • 記録は端末の中だけに保存されます。開発者にサーバーはなく、送信先が存在しません（プライバシーポリシー）
  • 入力を催促しません。通知も、連続記録も、達成率もありません。週に1回でも、まとめてでも構いません
  • 初日から使えます。1つ記録した時点で候補が変わります。ためこむ必要はありません。はじめて開いたときに好きな食材と苦手な食材を選ぶ画面が出ますが、飛ばしても構いません

アプリ内課金について

買い切りが1つあるだけで、月額の課金はありません。有料なのは献立表の写真読み取りだけです。初回の1回は無料で試せます（読み取りに失敗した回は消費しません）。

次の機能は無料のまま使えます。件数や日数の上限もかけていません。

  • 献立の手入力
  • 台帳（食べた / だめだった / 未挑戦 の記録）
  • 提案
  • 書き出し

このアプリは医療・アレルギーの管理を目的としたものではありません。医学的な助言や栄養に関する推奨は行いません。アレルギーや食事制限については、必ず医師にご相談ください。
